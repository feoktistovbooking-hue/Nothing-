# Конверт — Тайный Санта в Telegram

Мини-приложение и бот для игры «Тайный Санта». Сделано и поддерживается командой ИИ-агентов.

- `app/` — мини-приложение (React + Vite)
- `supabase/` — база и edge-функции (API, бот, cron)
- `content/` — тексты и документы
- `docs/` — спецификация, контракт API, команда, журнал решений
